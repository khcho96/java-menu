# 미션 - 점심 메뉴 추천


## 기능 구현 목록
1. 시작 메시지 출력
2. 코치 이름 입력 및 검증
   - 예외 사항
     - 형식이 올바르지 않은 경우 -> Validator
       - 잘못된 형식입니다.
     - 이름이 중복인 경우 -> Coach
       - 이름이 중복입니다.
     - 코치의 이름이 2자 미만 또는 4자 초과인 경우 -> Coach
       - 코치의 이름은 2자 이상 4자 이하로 입력해야 합니다.
     - 코치 인원이 2명 미만인 경우 -> Coaches
       - 코치는 최소 2명 이상 입력해야 합니다.
     - 코치 인원이 5명 초과인 경우 -> Coaches
       - 코치는 최대 5명까지 입력할 수 있습니다.
3. 코치 정보 저장 및 코치 이름 반환
4. 각 코치별 못 먹는 메뉴 입력 및 검증
   - 예외 사항
     - 형식이 올바르지 않은 경우(빈 값 허용) -> Validator
       - 잘못된 형식입니다.
     - 없는 메뉴인 경우 -> Menu
       - 없는 메뉴입니다.
     - 메뉴가 중복인 경우 -> Coach
       - 메뉴가 중복입니다.
     - 메뉴 개수가 2개 초과인 경우 -> Coach
       - 못 먹는 메뉴는 최대 2개까지 입력할 수 있습니다.
5. 못 먹는 메뉴 저장
6. 메뉴 추천
   1. 요일 별 카테고리 뽑기
      - 뽑은 카테고리가 기존에 뽑은 카테고리 목록에 2개가 있으면 다시 뽑는다.
   2. 카테고리 안에서 코치 별 메뉴 뽑기
      - 뽑은 메뉴가 코치가 먹지 못하거나 이미 먹은 메뉴이면 다시 뽑는다.
7. 결과 출력
